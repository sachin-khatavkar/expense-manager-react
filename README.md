🚀 Expense Manager Application

This is a frontend Expense Manager project developed using React, Bootstrap, and Vite.  
The application is integrated with PHP backend APIs and focuses on building a clean and responsive user interface.

🛠️ Tech Stack:
- React
- Bootstrap
- Vite
- PHP (Backend APIs)
- PostgreSQL

✨ Features:
- User Login UI
- Dashboard
- Add Expenses
- Responsive Design

📌 Status:
Currently in development and continuously improving with new features.
